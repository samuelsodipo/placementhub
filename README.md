# PlacementHub

## Overview

PlacementHub is a frontend web application designed to help university students organise, track and manage internship and placement applications in one central location.

## Features

- Application management dashboard
- Add, edit and delete applications
- Search and filter applications
- Track application statuses
- Kanban-style application board
- Dashboard statistics
- Dark and light mode
- Responsive user interface
- Persistent browser storage

## Technologies Used

- React
- TypeScript
- Vite
- CSS
- Browser LocalStorage

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed in your terminal.
